# 《度日：Daydrift》

> **一款以生活切片、街道漫游、日常互动与同游旅人为核心的像素生活模拟游戏。**

## 欢迎访问官方站点与生态

- 🌐 **官方主站**：[daydrift.example](https://daydrift.example)（游戏介绍、媒体画廊与最新动态）
- 📖 **开发者与玩家文档**：[docs.daydrift.example](https://docs.daydrift.example)（游玩手册、开服部署、模组规范）
- 🛒 **Mod 扩展中心**：[mods.daydrift.example](https://mods.daydrift.example)（官方与社区模组浏览、安全校验与下载）

## 下载与发行版本 (Releases)

请前往右侧的 **[Releases 页面](https://github.com/daydrift-studio/daydrift/releases)** 下载最新构建产物：

- **桌面客户端**：Windows (x64 / arm64)、Linux (x64 / arm64)、macOS (Universal)
- **移动客户端**：Android (APK / AAB)
- **跨平台独立服务端**：Windows Server、Linux Server、macOS Server
- **完整性校验**：每个版本均附带 `SHA256SUMS`、`release.json` 以及官方 Ed25519 数字签名 `release.json.sig`

本仓库（`daydrift-studio/daydrift`）是《度日：Daydrift》的**官方公开版本发行、社区更新与工单反馈平台**：
